# ページごとの役割
<dl>
  <dt>ホーム(最初に表示されるページ)</dt>
  <dd>便利屋の魅力、できることを伝える。予約へのナビゲート力も大事。</dd>
  <dt>サービス</dt>
  <dd>できることをリストアップ。どんなことでも相談してほしいということを伝える。</dd>
  <dt>料金</dt>
  <dd>料金設定をわかりやすく伝える。ほかのサイトだと料金系がよくわからないものも多いので、割とここが大事かも。</dd>
  <dt>予約</dt>
  <dd>電話番号と、メール送信フォーム。メールには画像添付機能がある。</dd>
</dl>
